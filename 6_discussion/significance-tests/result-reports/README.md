# Model Comparison Result Reports

[Up one level](../README.md) · [Repository README](../../../README.md)

[00_summary.md](00_summary.md) combines all nine paired model comparisons and links to the individual reports. Each report summarizes its primary result, supporting tables, and interpretation.

Table 7 of the paper uses seven of these comparisons. The Static Image–Static FEA and Dynamic Image–Dynamic FEA reports are additional analyses.

Producer notebooks and numerical outputs are documented in the [static comparison README](../static-significance-tests/README.md) and [dynamic comparison README](../dynamic-significance-tests/README.md). The notebooks write numerical CSVs; these Markdown reports are saved written summaries. See the [parent README](../README.md) for methods and inference scope.
