# 5.1.3 Image Control: Shuffled, unoptimized

[Up one level](../README.md) · [Repository README](../../../../README.md)

The ordered baseline configuration with shuffled frame order. The saved run has test accuracy **59.66%**.

The training notebook is [efficientnetV2-lstm-shuffled-unoptimized.ipynb](efficientnetV2-lstm-shuffled-unoptimized.ipynb). A rerun creates a new timestamped subdirectory here; it does not resume the saved run automatically.

[classification_report.txt](classification_report.txt) and [confusion_matrix.png](confusion_matrix.png) contain the saved evaluation. Training histories and phase logs are retained alongside the notebook. The training notebook generates `.keras` checkpoints locally.
