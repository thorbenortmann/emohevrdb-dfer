# 5.1.3 Image Control: Mean, unoptimized

[Up one level](../README.md) · [Repository README](../../../../README.md)

Mean pooling over frame features using the initial control configuration. The saved run has test accuracy **58.07%**.

The training notebook is [efficientnetV2-gap-unoptimized.ipynb](efficientnetV2-gap-unoptimized.ipynb). A rerun creates a new timestamped subdirectory here; it does not resume the saved run automatically.

[classification_report.txt](classification_report.txt) and [confusion_matrix.png](confusion_matrix.png) contain the saved evaluation. Training histories and phase logs are retained alongside the notebook. The training notebook generates `.keras` checkpoints locally.
